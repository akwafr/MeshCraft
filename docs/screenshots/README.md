# Screenshots

Images referenced by [`README.md`](../../README.md) and
[`README.fr.md`](../../README.fr.md), and available to the documentation vault.

They were captured from a throwaway instance seeded with the demo site
[`samples/site-demo.json`](../../samples/site-demo.json) (the fictional
"Horizon Festival", generic switches on RFC 5737 addresses), with synthetic
telemetry so that rates and charts are populated. UI language English,
1440×900 viewport at 2× scale.

| File | Screen |
|------|--------|
| `dashboard.png` | Dashboard — fleet counters, 24 h site traffic, ports by VLAN, active alerts, recent events |
| `monitoring.png` | Monitoring dashboard — fleet status, most loaded ports, event log |
| `devices.png` | Equipment — one card per switch with its port strip, throughput, PoE and state |
| `switch-detail.png` | Switch detail — header, port faceplate coloured by VLAN, switch summary |
| `ports.png` | Ports — every port of the site grouped by switch, with VLAN, link, traffic, PoE and neighbour |
| `topology.png` | Topology — site plan with location frames, link speeds, bidirectional rates and link diagnostics |
| `topology-dark.png` | Topology in the dark theme |
| `switch-profiles.png` | Configuration → Switch profiles — rule editor and preview on a real device |
| `port-profiles.png` | Configuration → Port profiles — profiles with the site VLAN plan |
