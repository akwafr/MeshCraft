# Documentation

The meshcraft architecture notes are an Obsidian vault. **English is the primary
version**; the French vault is kept alongside it as the original-language version.

| Language | Path | Entry point |
|----------|------|-------------|
| English (primary) | [`en/`](en/) | [`en/Index.md`](en/Index.md) |
| French | [`fr/`](fr/) | [`fr/Meshcraft - Index.md`](fr/Meshcraft%20-%20Index.md) |

Start with [`en/Index.md`](en/Index.md), then follow the wikilinks. Architecture
decisions (ADRs) are listed in
[`en/06-Decisions/Decision index.md`](en/06-Decisions/Decision%20index.md).

Each vault is self-contained: open `en/` or `fr/` as an Obsidian vault and every
wikilink resolves inside it. The two mirror each other note for note.
